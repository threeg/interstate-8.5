NOTE Every song is on this one page: no pagination, no lazy loading. Filtering is server-rendered — Apply reloads the page with the new query, so there is no in-place re-render state to design. Type defaults to Modest Mouse and alternate titles default to Show. Released and Played live are inert and read "Coming soon", not broken. Sorting ignores a leading "A"/"An"/"The" and any leading punctuation; anything that still starts with a digit or a non-Latin character falls into the "#" bucket, which sits after Z. The rail is sticky and stays docked below the site header while the ledger scrolls; letters with no songs under the current filter are muted and do not jump.
